# Hi, I'm Stefan 👋

I build open-source libraries for the browser — mostly around data visualization.

| Project | What it is |
| ------- | ---------- |
| **[d3-3d](https://github.com/Niekes/d3-3d)** | 3D visualization for [d3.js](https://d3js.org/), written in TypeScript. 415 stars, ~150,000 npm downloads a year. |
| **[beautiful-backgrounds](https://github.com/Niekes/beautiful-backgrounds)** | Web components for animated, generative backgrounds. |
| **[geometrica](https://github.com/Niekes/geometrica)** | Generative line art icons, as web components and SVG. |

I work on these in my spare time. There is no company funding them, so the
maintenance budget comes from the people who use them.

## Why sponsor?

**[d3-3d](https://github.com/Niekes/d3-3d)** needs it most. It is a genuinely
used library — it ends up in production dashboards, data journalism pieces and
teaching material — but it is maintained by one person, in the evenings, on top
of a day job.

Sponsorship pays for:

- **Issue triage and bug fixes.** Sponsorship buys a reply within a couple of days instead of whenever I get to it.
- **Types that stay correct.** Keeping `index.d.ts` accurate as d3, TypeScript and the DOM move on.
- **The documentation site.** Hosting, builds and the example gallery.
- **Time for new work.** More shapes, better performance, and eventually a WebGL renderer.

Everything stays free and BSD-3-Clause licensed. Sponsorship buys maintenance
time, not a paywall.
